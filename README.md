SOLMAR HEAT is a complete original open-world crime game set in Solmar City, a sun-soaked coastal metropolis of its own. Drive and steal cars, outrun the SCPD — helicopter police and roadblocks included — work 8 story missions for Mara Voss against Sal Kaine, buy weapons and cars, tune your garage ride, switch radio stations, and watch the day cycle turn, all offline in your browser.

## Run it

```sh
cd game && python3 -m http.server 8080
# then open http://localhost:8080
```
